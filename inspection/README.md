# 人工巡检与本地模型报告

入口：`http://192.168.31.220:5800/inspection`，驾驶地图首页也有「巡检工作台」链接。

1. 填写巡检名称，选择已有路线，或选择不绑定路线的定点检测。
2. 在原驾驶页面人工移动机器人，到点后回到巡检工作台点击检测。
3. 检测等待按钮操作后实际采集的新帧及其本地模型结果，保存对应图片、时间、模型、置信度、理由、SHA-256。有可靠定位时附加操作时位置；计划位置不作为已经到达的证明。
4. 路线最后一点完成后自动生成报告；也可提前结束。定点检测使用「结束并生成报告」。跳过、失败、未完成和低置信度结果分别记录，不计为正常。
5. 报告支持浏览器打印/保存 PDF，以及下载原始 JSON。历史报告保存在设备上，重启页面服务不会丢失。模型失败时仍有实际记录报告，可以重试模型分析。

## 数据与服务

- `inspection_service.py`：巡检状态、证据存储、报告生成和 Flask 路由，不包含运动控制。
- `local_model.py`：调用已运行的 `127.0.0.1:8888/v1/chat/completions`；模型名称由 `/v1/models` 获取，不写死。
- `camera/fire_detect.py` 是唯一相机读取者，新增 `/inspection.json` 暴露成对的新帧与检测输出。工作台预览代理其 `/raw.jpg`，不再次打开相机。
- 检测和报告通过 `/tmp/robot_local_vlm.lock` 跨进程串行调用本地 VLM，不并行争抢模型。报告分析期间检测可能等待。
- 记录存放在 `data/inspections/<id>/session.json`、对应 JPEG 与 `model_response.json`，数据目录被 Git 忽略。原始模型报告输出保留在设备，网页只呈现验证后的内容。
- 统计和覆盖结论由实际记录计算。模型不得更改统计；矛盾检测结果保留为待复核。报告中超出火焰烟雾范围的整体安全语句会被移除并标注；没有可用说明则标记生成失败。
- 报告仅覆盖已采集画面，不代表完整场地火灾风险评估。本页不实施自主行驶或灭火。
- 接口沿用现有局域网驾驶页面的访问边界，不适合直接公开到互联网。

## 验证

在板子上运行：

```sh
/usr/bin/python3 ~/robot/inspection/inspection_test.py
node ~/robot/web/inspection_ui_test.js
node ~/robot/web/web_drive_test.js
```

包括新帧验证、证据配对、失败重试、覆盖统计、矛盾结论、报告约束、重启恢复、HTML 转义和重复点击抑制。驾驶控件的原有回归也必须保持通过。
